# 适用对象与先修要求

## 适用对象

- **主要对象**：修读《高等数学 I（A 类）》并准备该课程**期中考试**的学习者。
- **次要对象**：承担该阶段复习带教、习题课或同伴辅导的授课者 / 助教，可用 [02_教学实施/课堂实施流程.md](../02_教学实施/课堂实施流程.md) 组织单元。
- **依据**：讲义封面「适用范围」、卷首「试卷骨架」与 `04_资源/参考/真题考点索引_2008-2025.md` 的逐卷考点统计。除这些材料已写明的内容外，未对学习者背景作任何额外假定。

## 先修基础

以下内容是读懂讲义所需的最低基础，依据讲义各章「概念与定理」段与知识库 Level 0–3 主笔记的范围归纳：

| 先修项 | 用到它的地方 |
| --- | --- |
| 函数、复合函数、反函数、基本初等函数及其图像 | C1、C3、C7 |
| 极限的直观概念与四则运算法则 | C1、C2 |
| 连续与间断的直观认识 | C3 |
| 导数定义、基本求导法则 | C4、C6 |
| 数学归纳法与简单不等式放缩 | C2、C8 |

> 待补充：学习者年级、专业、已修课程清单、入学水平与班级规模均未提供；不据此推断或分层。

## 不适用 / 边界

- **不适用于期末考试或后续内容复习**：积分、多元函数、级数、微分方程等不在本项目范围。材料交付清单明确 Level 4–6 为「长期概念底座，不在本次期中考试范围」，讲义亦未收录。
- **不替代真题卷**：本项目不含真题原件，只提供考点分布统计与按考点编写的练习；需要卷面请通过学校渠道获取。
- **不替代官方考核标准**：[03_总结与评估/效果评估.md](../03_总结与评估/效果评估.md) 的量规与前后测是项目内建议方案。
