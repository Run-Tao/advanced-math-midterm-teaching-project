## 2. 四维量规（A1–A4）

每维分「达标 / 部分达标 / 未达标」三级，按可观察行为判定，不换算分数。

| 维度 | 达标 | 部分达标 | 未达标 |
| --- | --- | --- | --- |
| **A1 条件判别** | 主动写全定理 / 定义条件（含闭连续、开可导、端点相等、$\delta$ 不依赖 $x$ 等） | 经提示后补全条件 | 未写条件或写错量词 |
| **A2 方法与流程** | 工具选择正确、七步 / 五步流程完整、列表齐全 | 工具对但跳步 | 工具选错或流程缺失 |
| **A3 计算与推导** | 结果与讲义答案速查一致，推导无跳步 | 思路对、计算有小错 | 结果错或主部相消未察觉 |
| **A4 表述规范** | 量词、$\D y=f'(x)\D x$、凹凸口径、五行表、左右极限均规范 | 个别表述不规范 | 表述影响结论或被扣分 |

各单元的主要观察维度见 [01_课程设计/知识点与题目对照表.md](../01_课程设计/知识点与题目对照表.md) §1 末列；例如 C2 重点看 A1/A2/A4，C5 重点看 A3/A4。

> 待补充（U07）：若后续提供官方评分标准，可在本表补「权重」与「分数换算」列。

## 3. 达成度判定（项目内口径）

对每单元目标 `O__`：

1. 后测两题在**该单元主要维度**上均达到「达标」；
2. [总结回顾.md](总结回顾.md) 的三问自检能独立答出，不需要翻方法卡；
3. 两条同时满足记为「达成」；只满足其一记为「部分达成」；均不满足记为「未达成」。

| 判定 | 建议动作 |
| --- | --- |
| 达成 | 进入下一单元 |
| 部分达成 | 只补做该单元「精讲后跟练」中对应 K 的题号 |
| 未达成 | 回看该 K 的例题精讲，重做前测两题，再测一次 |

> 上述判定规则是教学设计建议；**当前记录表为空白，未产生任何达成度结论**。

## 4. 记录与使用

- 记录载体：[评估记录模板.csv](评估记录模板.csv)，已预填 C1–C8、O 编号与前后测题号，评估列全部留空。
- 列含义：`前测会 / 前测未会` 记人数或「—」；`A1`–`A4` 填「达标 / 部分达标 / 未达标」；`达成度` 填「达成 / 部分达成 / 未达成」；`共性卡点 / 下次调整` 填文字；`记录日期 / 记录人` 待实际填写。
- 使用流程：前测 → 填前测列 → 跟练观察 → 后测 → 填 A1–A4 与达成度 → 按 §3 决定下一步 → 在 [总结回顾.md](总结回顾.md) 完成自归纳。

## 5. 数据缺口声明

本项目**没有**任何真实学情数据，因此：

- 不计算正确率、通过率、平均分；
- 不比较不同单元或不同群体的效果；
- 不给出「本讲义有效 / 无效」一类结论；
- 不使用任何推断值填补空白。

补齐数据的路径见 [00_总览/未确认信息清单.md](../00_总览/未确认信息清单.md) U08–U11；数据到位后再在本文件补「结果与分析」一节。
