# 高等数学 I（A 类）期中复习 · 教学项目

> 一个自包含、可直接打开使用的教学项目。以 **BOPPPS 六环**（导入 / 目标 / 前测 / 参与式学习 / 后测 / 总结）为组织主线，把《高等数学 I（A 类）期中考试复习讲义》整理成「目标 → 设计 → 实施 → 评估」可维护的课程包。

- **版本**：v1.0
- **建立日期**：2026-11-09
- **依据材料**：`04_资源/Downloads/讲义_高数I期中_分享版_2026-11-09.pdf`（31 页 / 48 书签 / 184 题）及其 LaTeX 源、复核脚本与题库
- **状态**：内容与资源已齐；未提供的事项（课时、考核权重、真实学情数据等）一律以「待补充」占位，集中在 [00_总览/未确认信息清单.md](00_总览/未确认信息清单.md)

## 3. 编号体系（全项目统一）

| 前缀 | 含义 | 范围 | 出现位置 |
| --- | --- | --- | --- |
| `C` | 教学单元 / 讲义章 | C1–C8 | 章节安排、知识点、对照表 |
| `O` | 可测教学目标 | O1–O8 | 教学目标、效果评估 |
| `K` | 核心知识点 | K1.1–K8.6 | 核心知识点清单、对照表、总结回顾 |
| `例 x.y` | 例题精讲 | 例 1.1–例 8.4，共 33 题 | 示例演示、讲义正文 |
| 原册题号 | 章末习题 | `S/T/P/W` 前缀，共 151 题 | 练习任务、讲义章末习题与答案速查 |
| `A` | 评估维度 | A1–A4 | 效果评估、评估记录模板 |

> 章末习题沿用题库原册编号（如 `S3.6`、`W5.4`），**不重新编号**，便于回查讲义答案速查表与四册题源。

## 4. 维护与复现

所有生成脚本在 `04_资源/Source/` 内，且 `Source/` 与 `Downloads/` 同级，脚本的相对路径可直接使用，不依赖本文件夹之外的任何路径。

```bash
cd "04_资源/Source"

# 1) 例题答案复核（必须全绿，否则生成器会拒绝）
PYTHONIOENCODING=utf-8 python verify_share_handout.py          # 期望 PASS 82 / FAIL 0

# 2) 生成讲义 .tex（含两道硬闸门）
PYTHONIOENCODING=utf-8 python build_share_handout.py

# 3) 编译：迭代至 .toc 与 .out 同时稳定（通常 3 遍）
xelatex -interaction=nonstopmode -halt-on-error 讲义_高数I期中_分享版.tex

# 4) 以 .toc 为真值对齐 PDF 书签，并归档到 ../Downloads/
PYTHONIOENCODING=utf-8 python align_share_bookmarks.py
```

改动规则：

1. **改讲解** → 编辑 `04_资源/Source/_share_notes.tex`，再走 §4 全流程；不要直接改生成出的 `.tex`。
2. **改题目或答案** → 编辑题库四册 `.tex`，先跑对应 `04_资源/复核/verify_*.py`，再重生成讲义。
3. **改教学设计** → 只改 `00_总览/`～`03_总结与评估/` 的 Markdown，不动资源目录。
4. 任何改动都要同步 [CHANGELOG.md](CHANGELOG.md)，并检查编号体系是否仍对得上 [01_课程设计/知识点与题目对照表.md](01_课程设计/知识点与题目对照表.md)。

> 环境说明（已验证）：复核与生成脚本需要 `sympy` / `mpmath` / `pymupdf`，编译需要 XeLaTeX 与已安装的 `tlnote.sty`。这些是工具依赖，不是项目内容；不同机器上请先确认可用。

## 5. 边界与占位

- 本项目**不含真题原件**，只在 `04_资源/参考/` 提供 2008–2025 十七套真题的考点分布统计；需要卷面请通过学校渠道获取。
- 本项目**不含任何真实学情数据**（成绩、正确率、通过率、学生反馈）；相关位置均为空白模板或「待补充」占位，见 [00_总览/未确认信息清单.md](00_总览/未确认信息清单.md)。
- 评分量规、前后测题号分配、单元组织方式均为**本项目给出的建议方案**，不是学校官方考核标准。
- 教学模式框架定义参考大学教师发展中心公开资料：对外经济贸易大学 <https://teachingcenter.uibe.edu.cn/xwdt/5adcbc9b1f3e4093808ff5325671b5cd.htm>、中国海洋大学 <https://jxfz.ouc.edu.cn/2020/0914/c17771a299525/page.htm>。此处仅采用其六环节划分组织文件职责。
