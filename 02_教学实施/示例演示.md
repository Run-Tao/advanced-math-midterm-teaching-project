## 2. 通用演示脚本（可用于任一例题）

1. **亮题**：只给题面，先让学习者独立判型 30 秒，不提示方法。
2. **提问点 1（条件）**：这道题用哪个定理？它的条件是什么？逐条口头确认。
3. **板书骨架**：只写方法卡的步骤编号与关键公式，完整计算留白。
4. **提问点 2（易错）**：本章易错点框里哪一条最可能在这里踩？为什么？
5. **补全解答**：与讲义解答逐行对照，标出「条件 / 工具 / 结果 / 收尾」四段。
6. **一句话迁移**：换一个数字或换一种未定式，结论会怎么变？
7. **交给学生**：立即做 [练习任务.md](练习任务.md) 中本单元「精讲后跟练」的题号。

> 待补充（U04）：授课形式、互动工具与分组方式未提供，故上述动作不绑定任何平台或人数。

## 3. 三个完整演示脚本（可直接照用）

### 演示 A · C2 例 2.1（$\eps$-$\delta$ 最简型）

| 步骤 | 演示内容 |
| --- | --- |
| 导入问题 | 「十七套真题的第 11 题年年考，为什么不能只背 $\delta=\eps$？」→ 引出 $\delta$ 必须由 $\abs{f-A}$ 的化简结果决定 |
| 条件确认 | 写全量词行：$\forall\eps>0\ \exists\delta>0$，$0<\abs{x-2}<\delta\Rightarrow\abs{f(x)-5}<\eps$；强调 $\delta$ 不含 $x$ |
| 板书骨架 | $\abs{(3x-1)-5}=3\abs{x-2}$ → 令 $3\abs{x-2}<\eps$ → $\delta=\eps/3$ |
| 易错提问 | 若写成 $\delta=\eps/3\cdot x$ 错在哪？若漏掉 $0<$ 会怎样？ |
| 回代验证 | 由 $\abs{x-2}<\eps/3$ 推回 $\abs{f-5}<\eps$，与讲义例 2.1 解答逐行对照 |
| 迁移 | 换成 $\lim_{x\to2}(5x-1)=9$，$\delta(\eps)$ 应是多少？（$\eps/5$） |
| 交给学生 | 做 `P1.1`、`P1.2`，再例 2.2 看可去间断点为何不影响定义 |

### 演示 B · C5 例 5.3（复合展开别漏高次项）

| 步骤 | 演示内容 |
| --- | --- |
| 导入问题 | 「$\sqrt{1+x+x^2}$ 的 $x^3$ 系数，只展到 $(1+u)^{1/2}$ 的 $u^2$ 项够不够？」 |
| 条件确认 | 目标次幂是 3；$u=x+x^2$，故 $u^2$ 含 $x^3$、$u^3$ 也含 $x^3$ |
| 板书骨架 | 写出 $(1+u)^{1/2}=1+\frac u2-\frac{u^2}{8}+\frac{u^3}{16}+o(u^3)$，再列 $u^2=x^2+2x^3+\cdots$、$u^3=x^3+\cdots$ |
| 易错提问 | 漏 $u^3$ 会得到什么错值？漏 $u^2$ 的 $2x^3$ 呢？（$-\frac1{16}$ / $-\frac14$，正确为 $-\frac3{16}$） |
| 收集系数 | $0-\frac14+\frac1{16}=-\frac3{16}$，与讲义一致；用 `verify_share_handout.py` 的 E5.3 断言背书 |
| 迁移 | 求 $x^4$ 系数时应把 $u$ 展开到几次？ |
| 交给学生 | 做 `T3.1`–`T3.5`，再用 `W2.5`、`W2.6` 检验系数反求高阶导 |

### 演示 C · C7 例 7.1（七步 + 五行列表）

| 步骤 | 演示内容 |
| --- | --- |
| 导入问题 | 「卷面常附 $y'$、$y''$ 提示，说明考的不是硬算导数，那考什么？」→ 考流程与列表 |
| 条件确认 | 定义域 $x\ne1$；分点必须含驻点 $0,2$ **和**导数不存在点 $1$ |
| 板书骨架 | 七步编号写满；$y'=\frac{x(x-2)}{(x-1)^2}$、$y''=\frac{2}{(x-1)^3}$；$k=\lim f/x=1$、$b=\lim(f-x)=1$ |

| 收尾 | 标出极大 $f(0)=0$、极小 $f(2)=4$、竖直 $x=1$、斜 $y=x+1$，再作图 |
| 交给学生 | 做 `S6.1`–`S6.6`，要求**先交列表再看图** |
